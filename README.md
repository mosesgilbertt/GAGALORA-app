# GAGAGLORA App

## Description

GAGAGLORA App is a web application built using TypeScript, the NEXT.js framework, and MongoDB as the database. This project is designed to be a valuable addition to your portfolio, so make sure to complete it thoroughly.

### Pages

- Register Page
- Login Page
- Home Page
- Promo Banner
- Ecommerce Info Details
- Featured Products (5-10 products) + “see-all” option
- Product Page
- Product List
- Search Feature
- Pagination Feature (using infinite scroll)
- Add to Wishlist Feature
- Product Detail Page
- Add to Wishlist Feature
- Meta Tag Implementation in the Head section based on product details
- Wishlist Page
- Wishlist List
- Remove Wishlist Feature

### Features

- Register Feature
